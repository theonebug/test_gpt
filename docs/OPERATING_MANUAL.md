## 1. Назначение

Изделие «Устройство управления углом включения тиристорного контактора» (далее — УУВ)
предназначено для формирования высокоточных, синхронизированных с напряжением
электрической сети импульсов управления для внешнего трехфазного тиристорного
контактора.

УУВ применяется в составе испытательных стендов для проверки изделий
на стойкость к токам короткого замыкания (ПКС).

- **1.1** УУВ обеспечивает управляющий импульс (далее по тексту — импульс)
  заданной начальной фазой включения внешнего силового контактора.
- **1.2** Выход устройства управляет последовательной цепью промежуточных
  оптотиристоров силового блока, коммутирующих силовые тиристоры контактора.
- **1.3** УУВ рассчитан на работу в составе стенда и обеспечивает заданную начальную
  фазу начала испытаний с точностью, указанной в разделе 2.
- **1.4** Полный цикл настройки и запуска выполняется с лицевой панели без
  подключения к ПК. Имеется выход синхронизации для электронного осциллографа.

> **Внимание.** УУВ коммутирует силовые цепи, гальванически связанные с сетью
> переменного тока (коммутация токов до 10 кА). Работы по подключению сети
> и нагрузке выполнять только при снятом питании (см. раздел 4).

## 4. Указание мер безопасности

**4.1.** УУВ коммутирует силовые цепи, гальванически связанные с сетью переменного
тока. Элементы силового блока (тиристоры, оптотиристоры) размещаются в силовой
стойке, выполненной с открытыми токоведущими частями, поэтому:

- **4.1.1** работы по подключению цепей синхронизации, нагрузки и силового блока
  выполнять только при снятом питании;
- **4.1.2** доступ к токоведущим частям должен быть ограничен дверью с блокировкой;
- **4.1.3** не допускать работу УУВ без штатной синхронизации и сторожа.

**4.2.** Порт связи RS-485 защищён от электростатических разрядов и наведённых
импульсных перенапряжений. Соблюдать требования развязки цепей «земли»
цифровой и силовой части.

**4.3.** Не изменять параметры, выходящие за допустимые диапазоны (фаза, длительность,
таймаут) без необходимости — это может привести к неконтролируемому включению силовой
нагрузки.

**4.4.** Ремонт и прошивку выполнять квалифицированным персоналом; при прошивке
снять напряжение с силовой части.

## 5. Подготовка к работе и порядок работы

### 5.1. Подготовка к работе

1. Убедиться, что силовая сеть отключена (контактор обесточен).
2. Выполнить необходимые подключения:
   - цепь синхронизации (140…180 В) — ко входу детектора перехода через ноль;
   - выход управления — к цепи промежуточных оптотиристоров силового блока;
   - выход синхронизации осциллографа — к электронному осциллографу;
   - интерфейс RS-485 (пары PA2/PA3, модуль XY-S485) — к ПК при необходимости.
3. Подать питание на устройство. Время готовности к работе — не более 3 с.
4. На дисплее появится статус готовности; светодиод «Готовность» загорится.

### 5.2. Проверка перед пуском

- Сведится ли **Готовность** (присутствует синхронизация);
- синхронизация отображена на экране («есть»);
- при отсутствии синхронизации запуск блокируется.

### 5.3. Установка начальной фазы включения

- Вращением энкодера устанавливается фаза включения (5…175°).
  Текущее значение отображается на дисплее.
- Фазу можно задать и по RS-485 (регистр 0).

### 5.4. Запуск и останов

| Действие | Результат |
|----------|-----------|
| Нажатие **RUN** / команда START | запуск испытаний согласно режиму |
| Нажатие **STOP** / команда STOP | немедленная остановка, состояние готовности |
| Команда «сохранить» по RS-485 | сохранение настроек во Flash |

> Во время работы с панели доступна только остановка; изменение фазы, меню
> и настроек игнорируется до возврата в состояние готовности.

### 5.5. Завершение работы

1. Нажать **STOP** либо дождаться автоматического завершения (режим «Таймер»
   или истечение аварийной выдержки).
2. Убедиться, что светодиод «Активный выход» погас, а на экране статус готовности.
3. Отключить силовое напряжение и питание устройства.

## 6. Органы управления и индикации

### 6.1. Панель управления

| Орган | Назначение |
|-------|-----------|
| **Кнопка RUN** | запуск (START) испытаний |
| **Кнопка STOP** | остановка (STOP) |
| **Энкодер** (вращение) | изменение фазы включения; в меню — навигация |
| **Кнопка энкодера (CLICK)** | подтверждение / вход в редактирование |
| **Длинное нажатие кнопки энкодера** | вход в меню настроек (в состоянии готовности) |

### 6.2. Светодиодная индикация

| Светодиод | Состояние | Значение |
|-----------|-----------|----------|
| **Питание** | горит | питание подано |
| **Готовность к пуску** | горит | устройство готово, синхронизация есть |
| **Активный выход** | горит | выход управления активен |
| **Авария / Сбой** | горит | авария (нет синхронизации, сбой) |

### 6.3. Дисплей

На дисплее отображаются: режим управления (LOCAL/REMOTE), статус RS-485,
синхронизация, фаза включения (градусы), состояние процесса и диагностика
(счётчики событий за 1 с).

## 7. Режимы работы и меню настроек

### 7.1. Режимы работы

- **CONTINUOUS (непрерывный)** — тиристор открывается на каждой полуволне на заданную
  фазу; соответствует режиму «Ручной (Постоянно)» ТЗ, работает до STOP или до истечения
  аварийного таймаута.
- **FIRST WAVE (срез первой полуволны)** — управляющий импульс формируется только на
  первой полуволне, остальные проходят без искажений до конца заданного времени.
- **TIMED (таймерный)** — задаётся длительность импульса 0,1…10,0 с (режим «Таймер»
  ТЗ), по истечении которой работа завершается автоматически.

### 7.2. Меню настроек

Меню открывается длинным нажатием кнопки энкодера (состояние готовности).
Вращение — навигация, CLICK — вход в редактирование/подтверждение, длинное нажатие —
закрытие меню с сохранением во Flash.

**Таблица 3 — Пункты меню**

| Пункт | Параметр | Диапазон / шаг |
|-------|----------|----------------|
| **PULSE** | Длительность управляющего импульса | 50…500 мкс, шаг 10 |
| **MODE** | Режим работы | CONTINUOUS / FIRST WAVE / TIMED |
| **TIME** | Время работы (TIMED) | шаг в соответствии с ТЗ (целевое 0,1…10,0 с) |
| **MAX RUN** | Аварийный таймаут непрерывного режима | 1…120 с |
| **FREQ WIN** | Допустимое отклонение частоты от 50 Гц | ±0,5…±10 Гц |
| **CALIB** | Калибровка опережения детектора нуля | 0…5000 мкс, шаг 10 |
| **CONTROL** | Режим управления | LOCAL / REMOTE |
| **RS485 BAUD** | Скорость RS-485 | 9600…115200 |
| **RS485 ADDR** | Адрес RS-485 | 1…247 |
| **RS485 PARITY** | Чётность | NONE / EVEN / ODD |
| **EXIT** | Закрыть меню и сохранить | — |

> Настройки применяются сразу после изменения, а запись во Flash выполняется
> при выходе из меню в состоянии готовности (стирание Flash останавливает ядро,
> поэтому во время работы тиристора сохранение откладывается).

## 8. Дистанционное управление по RS-485 (Modbus RTU)

УУВ работает как Modbus RTU slave по RS-485 (USART2). По умолчанию: адрес 1,
скорость 9600, чётность NONE, 8 бит данных, 1 стоп-бит. Параметры настраиваются в меню.

### 8.1. Функции протокола

| Функция | Код | Назначение |
|---------|-----|-----------|
| Чтение Holding-регистров | 0x03 | чтение настроек |
| Чтение Input-регистров | 0x04 | чтение состояния и счётчиков |
| Запись одного регистра | 0x06 | запись параметра / команды |
| Запись нескольких регистров | 0x10 | массовая запись |

### 8.2. Holding-регистры

| Адрес | Параметр | Диапазон |
|-------|----------|----------|
| 0 | Угол включения (фаза), градусы | 5…175 |
| 1 | Длительность импульса, мкс | 50…500 |
| 2 | Режим работы | 0 – CONT., 1 – FIRST WAVE, 2 – TIMED |
| 3 | Время работы при TIMED, мс | в соотв. с ТЗ |
| 4 | Аварийный таймаут, с | 1…120 |
| 5 | Допуск частоты, 0.1 Гц | 5…100 |
| 6 | Режим управления | 0 – LOCAL, 1 – REMOTE |
| 7 | Индекс скорости RS-485 | 0…4 |
| 8 | Адрес RS-485 | 1…247 |
| 9 | Чётность | 0 – NONE, 1 – EVEN, 2 – ODD |
| 10 | Команда | 1 – START, 2 – STOP, 3 – сохранить |
| 11 | Калибровка нуля, мкс | 0…5000, шаг 10 |

### 8.3. Input-регистры

| Адрес | Значение |
|-------|----------|
| 0 | Состояние (0 READY, 1 WAIT SYNC, 2 WAIT ZERO, 3 TEST, 4 FINISHED) |
| 1 | Синхронизация есть |
| 2 | Частота сети, 0.1 Гц |
| 3 | Полупериод, мкс |
| 4 | Фаза, градусы |
| 5 | Время с начала работы, мс |
| 6 | Переходы через ноль |
| 7 | Отбракованные события (помехи) |
| 8 | Импульсы CH1 |
| 9 | Импульсы CH2 |
| 10 | Срабатывания сторожа CH2 |
| 11 | Тиристор активен |
| 12 | Версия прошивки |

### 8.4. Ограничения безопасности

- В режиме LOCAL по RS-485 доступна только запись STOP и чтение; запись настроек
  отклоняется.
- Запись фазы и настроек разрешена только в состоянии READY (готовность).
- При нарушении ограничений устройство отвечает исключением.

### 8.5. Пример обмена

Запись команды START (регистр 10 = 1) для адреса 1:

```
Запрос:  01 06 00 0A 00 01 CRC16
Ответ:   01 06 00 0A 00 01 CRC16
```

## 9. Программное обеспечение для ПК

Для управления и мониторинга по RS-485 в состав проекта входит ПК-приложение
`thyristor_control.py` (каталог `tools/pc_app`, Python + PyQt5 + pyserial).

**9.1. Установка и запуск**

```bash
cd tools/pc_app
pip install -r requirements.txt
python thyristor_control.py
```

**9.2. Сборка .exe для Windows**

```bash
pip install pyinstaller
pyinstaller --onefile --windowed thyristor_control.py
```

**9.3.** Интерфейс: выбор порта/скорости/чётности/адреса, панель настроек
(фаза, импульс, режим), панель состояния (частота, фаза, счётчики, сторож),
журнал операций. Приложение опрашивает устройство каждые 500 мс.

## 10. Регламент технического обслуживания

**10.1.** Периодически, в зависимости от интенсивности работы, но не реже двух
раз в месяц, выполнять проверки:

- **10.1.1** проверять частоту сети (должна быть 50 Гц ± 2 %);
- **10.1.2** контролировать счётчики помех и сторожа на дисплее/по RS-485;
- **10.1.3** проверять надёжность подключения силовых линий и линии синхронизации;
- **10.1.4** проверять работоспособность сетевой синхронизации и выходов.

**10.2.** При повышении счётчиков помех — проверить фильтрацию входного сигнала
и состояние детектора перехода через ноль.

**10.3.** Перед высокоточной работой уточнять калибровку опережения детектора
(параметр **CALIB**).

**10.4.** Настройки сохраняются при выходе из меню; при некорректных данных
устройство переходит на значения по умолчанию (защита контрольной суммой
и версией структуры).
