1. Назначение

Изделие «Устройство управления углом включения тиристорного контактора» (далее — УУВ) предназначено для формирования высокоточных, синхронизированных с напряжением электрической сети импульсов управления для внешнего трехфазного тиристорного контактора.

УУВ применяется в составе испытательных стендов для проверки изделий на стойкость к токам короткого замыкания (ПКС).

  • 1.1 УУВ обеспечивает управляющий импульс заданной начальной фазы включения внешнего силового контактора.
  • 1.2 Выход устройства управляет последовательной цепью промежуточных оптотиристоров силового блока, коммутирующих силовые тиристоры контактора.
  • 1.3 Устройство рассчитано на работу в составе стенда и обеспечивает заданную начальную фазу начала испытаний с точностью по разделу 2.
  • 1.4 Полный цикл настройки и запуска выполняется с лицевой панели. Имеется выход синхронизации для электронного осциллографа.
Внимание. УУВ коммутирует силовые цепи, гальванически связанные с сетью переменного тока (коммутация токов до 10 кА). Работы по подключению сети и нагрузке — только при снятом питании (см. раздел 4).

3.1. УУВ представляет собой законченное устройство, устанавливаемое на испытательном стенде и состоящее из:

4. Указание мер безопасности

4.1. УУВ коммутирует силовые цепи, гальванически связанные с сетью переменного тока. Элементы силового блока (тиристоры, оптотиристоры) размещаются в силовой стойке, выполненной с открытыми токоведущими частями, поэтому:

  • 4.1.1 работы по подключению цепей синхронизации, нагрузки и силового блока выполнять только при снятом питании;
  • 4.1.2 доступ к токоведущим частям ограничен дверью с блокировкой;
  • 4.1.3 не допускать работу УУВ без штатной синхронизации и сторожа.

4.2. Порт связи RS-485 защищён от электростатических разрядов и наведённых импульсных перенапряжений. Соблюдать требования развязки цепей «земли» цифровой и силовой частей.

4.3. Не изменять параметры, выходящие за допустимые диапазоны (фаза, длительность, таймаут) без необходимости.

4.4. Ремонт и прошивку выполнять квалифицированным персоналом; при прошивке снять напряжение с силовой части.

5. Подготовка к работе и порядок работы

5.1. Подготовка к работе

  1. Убедиться, что силовая сеть отключена (контактор обесточен).
  2. Выполнить необходимые подключения:
    • цепь синхронизации (140…180 В) — ко входу детектора перехода через ноль;
    • выход управления — к цепи промежуточных оптотиристоров силового блока;
    • выход синхронизации осциллографа — к электронному осциллографу;
    • интерфейс RS-485 — к ПК при необходимости.
  3. Подать питание. Время готовности — не более 3 с.
  4. На дисплее появится статус готовности; светодиод «Готовность» загорится.

5.2. Проверка перед пуском

  • светодиод «Готовность» горит (синхронизация присутствует);
  • синхронизация отображена на экране («есть»);
  • при отсутствии синхронизации запуск блокируется.

5.3. Установка начальной фазы включения

Вращением энкодера устанавливается фаза включения (5…175°). Текущее значение отображается на дисплее. Фазу можно задать и по RS-485 (регистр 0).

5.4. Запуск и останов

ДействиеРезультат
Нажатие RUN / команда STARTзапуск испытаний согласно режиму
Нажатие STOP / команда STOPнемедленная остановка, состояние готовности
Команда «сохранить» по RS-485сохранение настроек во Flash
Во время работы с панели доступна только остановка; изменение фазы, меню и настроек игнорируется до возврата в состояние готовности.

5.5. Завершение работы

  1. Нажать STOP либо дождаться автоматического завершения.
  2. Убедиться, что светодиод «Активный выход» погас, а на экране статус готовности.
  3. Отключить силовое напряжение и питание устройства.

7. Режимы работы и меню настроек

7.1. Режимы работы

  • CONTINUOUS (непрерывный) — тиристор открывается на каждой полуволне; соответствует режиму «Ручной (Постоянно)» ТЗ, работает до STOP или до истечения аварийного таймаута.
  • FIRST WAVE (срез первой полуволны) — импульс только на первой полуволне, остальные проходят без искажений до конца заданного времени.
  • TIMED (таймерный) — задаётся длительность импульса 0,1…10,0 с (режим «Таймер» ТЗ), по истечении которой работа завершается автоматически.

7.2. Меню настроек

Меню открывается длинным нажатием кнопки энкодера (состояние готовности). Вращение — навигация, CLICK — вход в редактирование/подтверждение, длинное нажатие — закрытие меню с сохранением во Flash.

8. Дистанционное управление по RS-485 (Modbus RTU)

УУВ работает как Modbus RTU slave по RS-485 (USART2). По умолчанию: адрес 1, скорость 9600, чётность NONE, 8 бит данных, 1 стоп-бит. Параметры настраиваются в меню.

8.4. Ограничения безопасности

  • В режиме LOCAL по RS-485 доступна только запись STOP и чтение; запись настроек отклоняется.
  • Запись фазы и настроек разрешена только в состоянии готовности (READY).
  • При нарушении ограничений устройство отвечает исключением.

9. Программное обеспечение для ПК

Для управления и мониторинга по RS-485 в состав проекта входит ПК-приложение thyristor_control.py (каталог tools/pc_app, Python + PyQt5 + pyserial).

9.1. Установка и запуск

cd tools/pc_app
pip install -r requirements.txt
python thyristor_control.py

9.2. Сборка .exe для Windows

pip install pyinstaller
pyinstaller --onefile --windowed thyristor_control.py

9.3. Интерфейс и возможности

Интерфейс: выбор порта/скорости/чётности/адреса, панель настроек (фаза, импульс, режим), панель состояния (частота, фаза, счётчики, сторож), журнал операций. Приложение опрашивает устройство каждые 500 мс.

10. Регламент технического обслуживания

10.1. Периодически, в зависимости от интенсивности работы, но не реже двух раз в месяц, выполнять проверки:

  • 10.1.1 проверять частоту сети (должна быть 50 Гц ± 2 %);
  • 10.1.2 контролировать счётчики помех и сторожа (дисплей / RS-485);
  • 10.1.3 проверять надёжность подключения силовых линий и линии синхронизации;
  • 10.1.4 проверять работоспособность сетевой синхронизации и выходов.

10.2. При повышении счётчиков помех — проверить фильтрацию входного сигнала и состояние детектора перехода через ноль.

10.3. Перед высокоточной работой уточнять калибровку опережения детектора (параметр CALIB).

10.4. Настройки сохраняются при выходе из меню; при некорректных данных устройство переходит на значения по умолчанию (защита контрольной суммой и версией структуры).
