# Хост-симуляция логики FIRST WAVE / PassThrough

Хост-сборка (Windows/MinGW) проверяет логику прошивки **без** железа STM32,
эмулируя периферию фиктивными заглушками. Берутся ОРИГИНАЛЬНЫЕ файлы
`Core/Device/device.c` и `Core/Device/tiristor.c`, а HAL/BSP-зависимости
подменяются заглушками из `host/sim/` (подключаются первыми через include path).

## Что проверяется

- **FIRST WAVE**: первая полуволна обрезается по заданному углу,
  последующие открываются через настраиваемую задержку `PassMinDelayUs`
  (+ калибровка `ZeroCrossOffsetUs`) после перехода через ноль;
  импульс формируется на **каждой** полуволне (CC1IE не гасится);
- **CONTINUOUS / TIMED**: срез по углу на каждой полуволне, задержка
  монотонно зависит от угла 5...175° (регулирование не теряется).

Между переходами через ноль реально вызываются обработчики каналов
`Tiristor_Channel1_IRQHandler` / `Tiristor_Channel2_IRQHandler`
(функции `HOST_Mock_FireChannel1/2` в `sim/hal_mock.c`).

## Сборка и запуск

```
host> build_sim.bat
```

Требуется MinGW (`gcc`). По умолчанию используется `c:\dev\mingw64`;
при другом пути задайте переменную окружения `MINGW`.

## Структура

| Файл | Назначение |
|------|-----------|
| `sim/stm32f1xx_hal.h`     | фиктивные типы/регистры TIM2/GPIO, макросы HAL |
| `sim/stm32f1xx_hal_conf.h`| пустой конфиг |
| `sim/main.h`              | константы выводов (как в реальном main.h) |
| `sim/bsp_lcd.h`, `bsp_led.h`, `ui_colors.h` | заглушки экрана/светодиодов |
| `sim/hal_mock.c`          | реализация HAL, GPIO, TIM, BSP-LCD/LED |
| `sim/sync_stub.c`         | заглушка модуля синхронизации |
| `test_main.c`             | юнит-тест (возврат 0 = успех) |

> Важно: файлы подменяются только при компиляции хост-тестов. На прошивку
> и её сборку в CubeIDE эти заглушки никак не влияют.
