# Программа управления тиристорным контроллером

Связь по RS485, протокол Modbus RTU.

## Запуск

```
pip install -r requirements.txt
python thyristor_control.py
```

## Сборка .exe для Windows

```
pip install pyinstaller
pyinstaller --onefile --windowed thyristor_control.py
```

## Карта регистров

Holding registers, функции 0x03 / 0x06 / 0x10:

| Адрес | Параметр | Диапазон |
|-------|----------|----------|
| 0 | угол, градусы | 5...175 |
| 1 | длительность импульса, мкс | 50...500 |
| 2 | режим работы | 0 - CONTINUOUS, 1 - FIRST WAVE, 2 - TIMED |
| 3 | время работы, мс | 100...1000 |
| 4 | аварийный таймаут, с | 1...120 |
| 5 | допуск частоты, 0.1 Гц | 5...100 |
| 6 | режим управления | 0 - LOCAL, 1 - REMOTE |
| 7 | индекс скорости | 0...4 (9600...115200) |
| 8 | адрес RS485 | 1...247 |
| 9 | чётность | 0 - NONE, 1 - EVEN, 2 - ODD |
| 10 | команда | 1 - START, 2 - STOP, 3 - сохранить настройки |
| 11 | калибровка нуля, мкс | 0...5000, шаг 10 |

Input registers, функция 0x04:

| Адрес | Значение |
|-------|----------|
| 0 | состояние (0 READY, 1 WAIT SYNC, 2 WAIT ZERO, 3 TEST, 4 FINISHED) |
| 1 | синхронизация есть |
| 2 | частота сети, 0.1 Гц |
| 3 | полупериод, мкс |
| 4 | угол, градусы |
| 5 | время с начала работы, мс |
| 6 | переходы через ноль |
| 7 | отбракованные события |
| 8 | импульсы CH1 |
| 9 | импульсы CH2 |
| 10 | срабатывания сторожа CH2 |
| 11 | тиристор активен |
| 12 | версия прошивки |

## Ограничения безопасности

* в режиме LOCAL по RS485 доступно только чтение и команда STOP;
* запись угла и настроек разрешена только в состоянии READY;
* при запрете устройство отвечает исключением 0x04.

## Подключение

Модуль XY-S485 (автоматическое переключение направления, DE не используется):

* PA2 (USART2_TX) -> RXD модуля;
* PA3 (USART2_RX) <- TXD модуля;
* GND общий.
